Projects I Created

Turning coursework concepts into live web apps, mobile tools, APIs, and object-oriented programs.

Building real applications has been the most rewarding part of my degree. Working on both solo and team projects taught me how to structure clean code, collaborate with classmates using Git, and deploy working software so others can explore it.

Highlighted Builds

CampusAble Web App

Collaborated on a campus accessibility web application built with Angular and TypeScript and deployed on Google Cloud Run to make campus accessibility details easier to browse.

PhoneSpecs Mobile App

Developed a cross-platform mobile comparison app in Dart and Flutter for exploring and comparing smartphone hardware specifications side by side.

Mason Server Portfolio

Hand-coded a multi-page portfolio hosted on George Mason's server using HTML5, CSS3, and JavaScript with DOM events, animations, and W3C-valid markup.

Node.js APIs & Java OOP

Created backend endpoints with Node.js and MySQL alongside modular object-oriented Java programs practicing class structure and file logic.

What Building Taught Me

  • Breaking features into smaller pieces makes debugging much faster and less stressful.
  • Clear communication and Git workflows keep group builds organized from start to finish.
  • Testing early across screens and validating HTML prevents last-minute headaches.
